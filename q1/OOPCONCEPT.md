# ILA 3-1: Applying the Four Pillars of OOP

## Sari-Sari Store Inventory System

### 1. Encapsulation
The concept can be used by grouping variables like Price, Product name, Product description.This makes the code less confusing and improves code readability.

### 2. Abstraction
The concept can be used by hiding not too important details like the procedures on how it was made and how it was packaged. The variables that are shown are the most important ones like Product name, product expiration date, and product allergens. This makes the code very simple and easy to read

### 3. Inheritance
This makes variables like Expiration date and date made be used by many objects that share the same variables. This eliminates the need for defining new variables that serve the same purpose.

### 4. Polymorphism
Polymorphism makes the same variables have different outputs depending on what they are, for example if i sold a piece of candy with function sell( ) it will give me 5 pesos and when i sell a can of coke it will give me 25 pesos. This makes code faster by eliminating a lot of if else or switch-case statements.
